# API Overview

Base URL: `/api/v1`

Implemented endpoints:
- `POST /auth/login`
- `GET /auth/me`
- `GET/POST /users` (admin protected)
- `GET/POST /projects`
- `GET /projects/{id}`
- `POST /uploads`
- `POST /processing/start`
- `GET /processing/{id}`
- `GET /parcels`
- `GET /parcels/{id}`
- `POST /parcels/{id}/review`
- `POST /ground-tasks`
- `GET /reports/summary`
- `GET /exports/parcels.geojson`
- `GET /exports/parcels.csv`
